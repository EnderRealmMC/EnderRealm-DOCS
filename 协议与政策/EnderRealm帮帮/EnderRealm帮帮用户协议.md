# EnderRealm帮帮 用户协议

**版本生效日期：2026年6月4日**  
**运营主体：** CNEnderCraftStudios（非法人组织）  
**联系方式：** policy@enderrealm.cn

**第一条 协议范围**  
1.1 本协议是您与CNEnderCraftStudios（以下简称“工作室”）之间关于使用“EnderRealm帮帮”（以下简称“本服务”）的协议。  
1.2 本服务是一个通用人工智能智能体，可以自主搜索网络、查询百科、阅读文档等，用来回答问题、闲聊或编写代码。本服务的源代码完全公开，可在GitHub上查看。  
1.3 点击“同意”并使用本服务，代表您已经阅读、理解并同意本协议的全部内容。

**第二条 服务状态**  
2.1 本服务按“现有状态”提供。所有回答均由人工智能自动生成，**不代表工作室的官方立场**，工作室**不对回答的准确性、完整性、及时性做任何保证**，也不保证服务永远不会中断。  
2.2 工作室有权根据运营需要修改、暂停或终止部分或全部服务，重要变动会提前公告。  
2.3 本服务**永久免费**，工作室承诺绝不向用户收取任何费用。

**第三条 使用规范**  
3.1 您不得利用本服务做任何违反中国法律法规的事情，包括但不限于：  
（1）输入、生成、传播违法信息或破坏公序良俗的内容；  
（2）利用本服务进行自动攻击、传播病毒或干扰服务正常运行。  
3.2 工作室有权对聊天记录进行技术审查，但这不是日常主动行为，只在收到举报、系统发现异常或法律要求时才会进行。

**第四条 未成年人使用**  
未满14周岁的用户，必须在监护人阅读、理解并同意本协议及隐私政策后，在监护人的监督下使用本服务。

**第五条 责任限制**  
在法律允许的最大范围内，工作室不对任何间接、偶然、连带或衍生损失承担责任。对于直接损失，由于本服务永久免费，工作室的赔偿金额为零。这一条不适用于工作室故意或重大过失造成的人身伤亡或财产损失。

**第六条 法律适用与管辖**  
本协议受中华人民共和国法律管辖。因本协议产生的争议，应提交工作室所在地有管辖权的人民法院解决。

**第七条 可分割性**  
如果本协议的任何一条被认定为无效或无法执行，其余条款仍然完全有效。

**第八条 联系方式**  
协议相关事宜请联系：policy@enderrealm.cn
