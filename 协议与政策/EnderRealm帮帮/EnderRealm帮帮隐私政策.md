# EnderRealm帮帮 隐私政策

**版本生效日期：2026年6月4日**  
**运营主体：** CNEnderCraftStudios（非法人组织）  
**联系方式：** private@enderrealm.cn

**第一条 我们收集哪些信息**  
1.1 **聊天内容**：您发送的消息，以及助手返回的回答（包括搜索、查百科等中间结果）。这些信息用于提供对话服务。  
1.2 **会话标识**：系统生成的会话ID和令牌，用于区分不同用户、保持对话状态。  
1.3 **大致位置**：每次对话开始时，系统会根据您的IP地址判断您的大致区域（中国大陆精确到城市，例如“北京市”；其他国家和地区精确到国家或地区，例如“美国”“台湾”“香港”）。这个位置信息只在当次对话中临时使用，**我们不会存储您的原始IP地址**，只会存储解析出来的区域名称。当您删除该段对话记录时，这个区域信息也会随之删除。我们**不收集您的精确位置或GPS数据**。

**第二条 第三方服务提供方**  
2.1 本服务的核心回答功能由**小米MiMo开放平台的MiMo模型**提供。您的聊天内容会被发送给MiMo模型进行处理，这个过程发生在**中华人民共和国境内**。根据小米的隐私政策，**未经您同意，小米不会将您的聊天内容用于模型训练或其他用途**。小米的相关协议见：  
- 用户协议：https://platform.xiaomimimo.com/docs/terms/user-agreement  
- 隐私政策：https://privacy.mi.com/XiaomiMiMoPlatform/zh_CN/  
2.2 本服务在运行中可能会自动调用网络搜索、网页抓取等公开工具。这些工具只接收关键词或网址，**不会包含您的会话ID或IP地址**。

**第三条 数据存储与跨境传输**  
3.1 本服务使用Cloudflare的全球网络，您的数据会存储在**境外服务器**上（具体国家或地区由Cloudflare自动分配）。  
3.2 聊天记录默认保存**7天**，每次对话后有效期会自动延长。过期后自动删除。

**第四条 我们如何使用您的信息**  
4.1 提供、维护、改进本服务。  
4.2 对聊天内容进行必要的技术审查（规则见用户协议第三条）。  
4.3 进行匿名的使用情况统计分析。

**第五条 我们何时会分享您的信息**  
除以下情况外，我们不会向第三方分享您的信息：  
（1）您明确同意；  
（2）有明确管辖权的司法机关、行政机关或法律授权的组织，按照法定程序要求我们提供；  
（3）为防止严重危害他人权益的行为（例如恶意攻击服务器、传播违法信息）。

**第六条 您的权利**  
您有权**删除**您的聊天记录、**导出**您的聊天记录、**导入**历史聊天记录。

**第七条 数据安全**  
我们使用加密传输（HTTPS）保护您的数据。但请注意，互联网传输无法做到100%绝对安全。

**第八条 未成年人隐私**  
未满14周岁的未成年人必须在监护人同意并监督下使用本服务。如果我们发现未经监护人同意收集了未成年人的信息，会尽快删除。

**第九条 可分割性**  
如果本政策的任何一条被认定为无效或无法执行，其余条款仍然完全有效。

**第十条 政策更新**  
本政策如有重大变更（例如收集信息的类型、存储方式发生实质变化），我们会通过官方渠道公告。您继续使用即表示同意更新后的政策。

**第十一条 联系方式**  
隐私相关问题请联系：private@enderrealm.cn
