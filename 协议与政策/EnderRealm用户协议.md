# EnderRealm 用户协议

**生效日期：2026-05-26**

## 一、接受条款

**1.1 协议主体**

本《EnderRealm 用户协议》（下称“本协议”）是您与 CNEnderCraftStudios（下称“工作室”或“我们”）之间，就您使用 EnderRealm 服务器（下称“本服”）服务所订立的合同。

**1.2 根本规则与协议体系**

《EnderRealm 基本章程》（下称“《基本章程》”）是本服的根本规则文书，本服的一切运营活动、管理行为、规则制定均以《基本章程》为最高依据。本协议受《基本章程》制约，任何条款不得与《基本章程》相抵触。

本协议与以下文书共同构成您使用本服的完整规则体系：

- 《EnderRealm 基本章程》：本服的根本规则文书。
- 《EnderRealm 玩家守则》（下称“《玩家守则》”）：依据《基本章程》制定，是管理玩家日常行为的直接依据。
- 《EnderRealm 隐私政策》（下称“《隐私政策》”）：依据《中华人民共和国个人信息保护法》制定，规定我们如何收集、使用和保护您的个人信息。

本协议为合同性质文书，与上述规则文书并行。本协议主要规定您与工作室之间的服务使用关系、账户规则、虚拟物品规则、知识产权、责任限制等合同事项。涉及社群管理、玩家行为规范及处罚的事项，依据《基本章程》及《玩家守则》处理；涉及个人信息处理的事项，依据《隐私政策》处理。

**1.3 同意机制**

您在首次连接本服时，系统将弹出独立的确认窗口，其中包含本协议的完整文档链接。您需要阅读并主动点击“同意”按钮，方视为您已理解并接受本协议的全部条款。

只有在您点击“同意”后，注册流程才会继续。此后您每次连接本服，均受本协议约束。

如您点击“拒绝”或关闭窗口，注册流程将终止，您将无法使用本服服务。

**1.4 未成年人特别提示**

如您未满 18 周岁，请在父母或其他监护人的陪同下阅读本协议，并在获得其明确同意后使用本服。如您未满 14 周岁，须由监护人代为同意本协议。

## 二、账户规则

**2.1 EnderRealm 账户系统**

本服使用独立的 EnderRealm 账户系统进行身份识别与管理。您在游戏内的全部数据、资产及记录，均与您的 EnderRealm 账户关联。

**2.2 账户系统的独立性**

EnderRealm 账户系统与 Mojang / Microsoft 的正版验证体系相独立。您所使用的 Minecraft 客户端的授权状态，不影响您在本服的账户注册与游戏体验。

然而，您购买和使用 Minecraft 客户端的行为受您与 Mojang 之间达成的 [《Minecraft 最终用户许可协议》](https://www.minecraft.net/zh-hans/eula) 约束。您应自行确保对客户端的使用符合该协议。本服不支持、不鼓励任何违反该协议的行为。

**2.3 RUID：账户的唯一身份标识符**

在 EnderRealm 账户系统中，每个账户由唯一的 RUID（Realm Unique ID，本服内部唯一身份标识符）进行索引。RUID 是您账户的身份标识字符串，用于关联该账户下的所有游戏数据、虚拟物品及处罚记录。

**2.4 与 Minecraft 身份标识的关系**

您的 Minecraft 客户端在连接本服时，会提供您的 Minecraft 身份标识：

- Java 版：提供 Minecraft UUID。
- 基岩版：提供 XUID。

上述标识符在 EnderRealm 账户系统中作为绑定凭据使用。系统通过将您的 Minecraft 身份标识与您的 EnderRealm 账户建立绑定关系，以便您在后续连接时无需重复登录。

**2.5 账户的创建**

根据您使用的客户端平台，EnderRealm 账户的创建方式不同：

- **Java 版**：在您同意本协议并开始注册流程后，您需自行注册 EnderRealm 账户。您需输入自定义的 RUID，仅限英文字母（A-Z、a-z）与数字（0-9）的组合，不得包含空格、符号或特殊字符。经系统校验通过且未被他人占用后，该 RUID 即成为您 EnderRealm 账户的身份标识，并与您当前的 Minecraft UUID 建立绑定关系。
- **基岩版**：在您同意本协议并开始注册流程后，系统将依据您的 XUID 自动创建一个 EnderRealm 账户，并生成系统 RUID。该系统 RUID 具有以下特殊性质：
  - 与当前基岩版 XUID 硬绑定，不可用于手动输入登录。
  - 仅限当前基岩版账户使用，不可用于 Java 版客户端或任何其他基岩版账户登录。
  - 该绑定关系持续保留于系统中。

**2.6 退出登录与账户切换**

您可使用“退出登录”功能退出当前 EnderRealm 账户，回到登录界面。退出登录后，您可选择：

- 登录您在此前已注册的、归属于您的任何其他 EnderRealm 账户（输入对应的 RUID 及凭证）；
- 注册一个新的 EnderRealm 账户。

**跨平台登录说明**：您的 EnderRealm 账户与客户端平台无关。例如，您在 Java 版上注册的账户，可在基岩版客户端的登录界面通过输入 RUID 和凭证进行登录，反之亦然。账户的资产与数据完全互通。

对于基岩版玩家：退出登录后，您可登录已有的（包括在 Java 版上注册的）账户或注册新账户。若您注册或登录了新的 EnderRealm 账户，该新账户将与您的 XUID 建立绑定关系，原系统 RUID 的绑定关系将处于未激活状态。如后续新绑定的账户被取消绑定，系统将自动回退至原系统 RUID 的绑定状态。

Java 版玩家退出登录后，必须重新输入 RUID 及凭证方可再次进入游戏。

**2.7 账户所有权**

您的 EnderRealm 账户及与该账户关联的全部游戏数据、虚拟物品的所有权归工作室所有。您仅依据本协议享有该账户的使用权。未经工作室明确书面许可，您不得将 EnderRealm 账户出售、出租、转让、赠与或以任何形式交由他人使用。违反此项规定的，我们有权不予通知即停止对该账户的服务。

**2.8 账户安全、责任与申诉**

您作为账户的注册使用者，对自身 EnderRealm 账户的凭证安全及客户端设备安全负有妥善保管的责任。因您自身的过失（如凭证泄露、设备失控）导致的账户被他人使用、数据丢失、虚拟物品损失、违规连带处罚等后果，由您自行承担。

若您因非自身原因失去对账户的控制（例如遗忘凭证或怀疑被盗），您有权向我们申请找回。我们将在验证您提供的、与账户创建或历史使用记录相符的证明材料（如原始绑定邮箱等，具体以我们当时的申诉要求为准）后，尽力协助您恢复对账户的控制。但最终是否能够找回，取决于您提供证明的充分性及我们基于安全考量的最终判断。我们对无法通过申诉找回账户不承担责任。

**2.9 账户注销**

您有权随时申请注销您的 EnderRealm 账户。账户注销后，与该账户关联的全部游戏数据、虚拟物品及记录将被永久删除或匿名化处理，且无法恢复。

账户注销的具体申请方式、处理流程及数据处理细则，以《隐私政策》的相关规定为准。
