## 文档规范

编写文档时，请遵循以下规范：

1. **一级标题**：每篇文档必须以一级标题（`#`）开头，作为文档标题。
2. **原作者声明**：第二行声明原作者，格式为 `> 作者：xxx`。
3. **正文内容**：作者声明之后为正文内容。
4. **基本格式**：必须具备基本的 Markdown 格式。如需使用分标题，请使用正确的标题层级（`##`、`###` 等）。

示例：

```markdown
# 文档标题

> 作者：玩家昵称

正文内容...

## 分标题

更多内容...
```
